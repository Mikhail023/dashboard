# Dashboard для Windows

Тот же интерфейс и общие исходники `../src`. Windows-сборка отличается установщиком,
обычной рамкой окна, сочетаниями Ctrl вместо ⌘ и отсутствием macOS Touch ID.

```powershell
npm ci
npm run build:windows
```

Результат: `release/windows/Dashboard-Setup-<version>-x64.exe` — NSIS-установщик
для Windows 10/11 x64. Node.js конечным пользователям не нужен.
SQLite хранится в `%APPDATA%/Dashboard`, отдельно от каталога установки.
Удаление/обновление приложения сохраняет данные. Новая версия предлагает скачать
обновление, затем перезапустить приложение. Перед установкой создаётся резервная копия.

Для сборки и проверки нативного SQLite используйте Windows, как в GitHub Actions.
Неподписанный установщик может вызвать предупреждение Windows SmartScreen.
