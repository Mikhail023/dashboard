# Dashboard для macOS и Windows

Локальный персональный органайзер для macOS и Windows на Electron 44.5.1, React 18, TypeScript strict, Vite и SQLite. Русский интерфейс, две темы, без облачной синхронизации, аналитики и внешних API.

## Установка

Установщики публикуются в [GitHub Releases](https://github.com/Mikhail023/dashboard/releases/latest).

- **macOS Apple Silicon:** DMG с суффиксом arm64.
- **macOS Intel:** DMG с суффиксом x64.
- **Windows 10/11 x64:** Dashboard-Setup-<version>-x64.exe.

macOS: откройте DMG и перетащите приложение в Applications. Windows: запустите
установщик, выберите папку и ярлыки. Данные хранятся отдельно от приложения;
обновление сохраняет существующие SQLite-данные и настройки. Первый запуск
предложит создать локальный профиль. Демо загружается только по кнопке.

Текущие сборки не подписаны сертификатами Apple Developer / Windows.
Система может показать предупреждение о неизвестном издателе.

## Разработка и сборка

Нужны Node.js 22.12+ и npm, на macOS — Xcode Command Line Tools,
на Windows — инструменты C++ для сборки нативных модулей, если нет prebuild.
Для разработки используйте ОС, для которой собираете приложение.

```sh
npm ci
npm run dev
npm run lint
npm test
npm run compile
npm run test:smoke
npm run test:acceptance
npm run build:mac       # macOS DMG + ZIP, arm64 и x64
npm run build:windows   # Windows NSIS, x64
```

## Структура проекта

- `src/main` — Electron, SQLite, IPC, backup и обновления.
- `src/preload` — защищённый мост renderer/main.
- `src/renderer` — общий интерфейс React для обеих ОС.
- `src/shared` — модели, парсеры и расчёты.
- `migrations` — безопасные изменения существующей базы.
- [`mac/`](mac/README.md) — настройки и инструкции macOS.
- [`windows/`](windows/README.md) — настройки и инструкции Windows.
- `build/` — общая конфигурация упаковки и фирменная иконка.
- `tests/`, `scripts/` — регрессионные и runtime-проверки.

## Обновления

При запуске и каждые 6 часов приложение проверяет новую версию в GitHub Releases.
В Windows предлагает загрузку и перезапуск с резервной копией. В неподписанной
macOS-сборке предлагает открыть страницу скачивания DMG. Проверить вручную:
Dashboard → Проверить обновления. Подробности и публикация: [docs/releases.md](docs/releases.md).
Пользователям версии 1.2 и старше нужно один раз вручную установить версию 1.3.

## Что работает

- **Вход:** один локальный профиль, имя/email/эмодзи-аватар, scrypt с индивидуальной солью, проверка повтора пароля, лимит попыток, блокировка, автоблокировка 1/5/15/30 минут, блокировка при сне/блокировке macOS. Touch ID доступен при поддержке устройства. Смена пароля; сброс — только с удалением базы и двумя подтверждениями.
- **Дашборд:** показатели проектов, недельная аналитика задач, ближайшие события, прогресс, таймер, финансы и последние заметки. Названия, порядок и видимость KPI и виджетов настраиваются; заголовок и подзаголовок редактируются. Значения рассчитываются из данных. Настройки виджетов сохраняются при закрытии диалога.
- **Заметки:** папки и цвета, поиск по тексту, теги, сортировки, закрепление, архив, корзина на 30 дней. TipTap: заголовки, жирный/курсив, списки, чекбоксы, код, цитаты и ссылки. Автосохранение 500 мс; экспорт Markdown/PDF.
- **Задачи:** список и канбан с перетаскиванием, проекты, приоритеты, сроки, исполнители, подзадачи, фильтры и таймер. Длинный список задач виртуализируется.
- **Календарь:** месяц/неделя/день, навигация, создание по дате/слоту, редактирование и перенос, весь день, повторы ежедневно/еженедельно/ежемесячно, сроки задач, локальные уведомления.
- **Финансы:** счета и валюты, доход/расход/перевод, категории, фильтры, графики, счета-фактуры с позициями, PDF/CSV. Оплата атомарно создаёт доход; повторная оплата запрещена. Суммы в расчётах округляются до копеек.
- **Проекты:** карточки/таблица, статусы, прогресс из задач, связанные заметки, события, операции, счета и учтённое время.
- **Настройки:** профиль, тема/системная тема, плотность, валюта, начало недели, безопасность, резервные копии, JSON, демо-данные.
- **Общее:** поиск ⌘K, быстрые действия, уведомления, трей с управлением таймером, справка и клавиатурная навигация.

Перетаскивайте задачу за свободную область карточки (у верхнего края); кнопки внутри карточки выполняют собственные действия. Менять статус можно также в форме задачи. Закрытие окна оставляет приложение в строке меню. Для полного выхода используйте ⌘Q.

## Хранение и безопасность

```
~/Library/Application Support/Dashboard/
  dashboard.db
  dashboard.db-wal
  dashboard.db-shm
  Backups/             # последние 14 резервных копий
  logs/dashboard.log
```

SQLite открывается **только в main**. Включены WAL и foreign keys; миграции версионируются в `migrations`. Preload предоставляет ограниченный типизированный мост, `contextIsolation: true`, `nodeIntegration: false`, sandbox включён. Каждый IPC-запрос проверяет отправителя и авторизацию; записи проверяются Zod; SQL-значения параметризованы, имена таблиц выбираются из белого списка. Данные не доступны через API до входа.

В production CSP запрещает соединения (`connect-src 'none'`), новые окна и внешняя навигация запрещены; webRequest отклоняет внешние HTTP/HTTPS-запросы. Шрифт Inter и иконки включены в сборку. В dev разрешено только соединение с локальным Vite для HMR.

**Пароль защищает доступ к интерфейсу, но не шифрует SQLite и резервные копии.** Для защиты данных на диске используйте FileVault. Человек с прямым доступом к файлам может прочесть незашифрованную базу.

### Расширение для SQLCipher

`src/main/storage.ts` определяет `DatabaseFactory`; `Repository` получает её через конструктор. SQLCipher-совместимый драйвер можно подключить без изменения renderer/IPC. Для полноценного шифрования необходимо вынести публичный профиль и параметры KDF в отдельный небольшой файл, открывать зашифрованную базу только после получения ключа, закрывать её и очищать ключ при блокировке, а резервные копии создавать через тот же адаптер. Миграция существующей базы должна быть атомарной, с проверкой копии и сменой пароля через rekey. Сейчас этот адаптер **не реализован**, переключателя, обещающего шифрование, нет.

## Резервные копии, импорт и экспорт

- Автокопия создаётся при первом запуске за сутки через SQLite backup API, корректно учитывающий WAL. Можно создать копию вручную.
- Восстановление проверяет целостность, таблицы, сущности и профиль, сохраняет текущую базу, заменяет файл и блокирует сессию. Потребуется пароль из восстановленной копии.
- JSON содержит рабочие записи, настройки интерфейса и публичные данные профиля; **хэши паролей и соль не экспортируются**. Импорт объединяет записи по UUID в одной транзакции. Существующий пароль не меняется.
- Перед импортом и восстановлением создаётся резервная копия.
- Удаление демо-данных затрагивает записи, созданные демонстрационным наполнением. Если вы редактируете демо-запись, она остаётся демонстрационной. Записи, на которые ссылаются созданные вами данные (например, счёт с новой операцией), сохраняются вместе с необходимыми зависимостями.
- Полный сброс удаляет активную базу и профиль, но сохраняет файлы Backups. При необходимости удаляйте резервные копии отдельно через Finder.

## Проверки и границы версии

Vitest проверяет миграции, WAL/foreign keys, сохранение и корзину, валидацию, демо-наполнение, резервные копии, атомарность импорта, хэширование, лимит попыток, прогресс, финансовые расчёты, переводы и повторы событий. Интерактивные проверки выполнялись в настоящем Electron через Playwright на отдельной тестовой базе; личные данные пользователя не использовались.

- Touch ID и уведомления зависят от оборудования и разрешений macOS; физический Touch ID не автоматизировался.
- Уведомления отправляются, пока приложение запущено и разблокировано. После полного завершения процесса фонового демона нет.
- Повторы: ежедневно, еженедельно, ежемесячно, ежегодно, рабочие/выбранные дни и интервал. Перенос события меняет всю серию; исключения отдельных событий и произвольный RRULE не реализованы. Выполнение повторов задач сохраняется отдельно.
- Валюты не конвертируются: сводки показывают выбранную валюту, переводы разрешены между счетами одной валюты.
- Пользовательская настройка меняет данные и композицию дашборда в рамках дизайн-системы; свободного графического редактора с произвольными координатами нет.
- Минимальный размер окна — 1100×700. Приложение предназначено для macOS, мобильная версия не предусмотрена.
- Настоящее шифрование БД и Apple notarization требуют отдельной реализации/учётной записи разработчика.

### Итоговая проверка сборки

Для версии 1.1.1 прошли 35 тестов Vitest, TypeScript strict, проверка неиспользуемого кода и ESLint. `npm run test:smoke` проверяет существующие разделы в Electron; `npm run test:acceptance` проходит Smart Input, связи, Inbox, повторы, бюджеты/цели, сетку, темы, Timeline/Focus, экспорт, перезапуск и Safety Restore. Все сценарии используют отдельные временные базы. Перед этими командами выполните `npm run compile`.

Проверка предыдущей версии включала смену пароля, отсутствие Node.js в renderer и блокировку внешнего соединения; соответствующая архитектура сохранена. Финальные результаты упаковки версии 1.1 перечислены в отчёте о доработке.

Визуальная сверка выполнена по `docs/design-concept.png` в настоящем Electron через Playwright (обычная браузерная вкладка не предоставляет IPC). Проверены 1536×1024 и минимальное окно 1100×700: палитра, Inter, сетка/навигация, радиусы и отступы карточек, иконки, обе темы. Убрана лишняя высота виджетов; горизонтального переполнения нет. Осознанные отличия от концепта: реальные расчётные данные, элементы настройки, дополнительный статус локального хранения и вертикальная прокрутка; это не статическая копия изображения.

Версия 1.1.1 исправляет поиск/историю повторов, отмену выполнения через канбан, автосохранение заметок и импорт удалённых финансовых записей. Подробности повторного аудита — в `docs/implementation-report.md`.
